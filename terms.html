1. The software

Game Bridge (“the App”) is a macOS application that runs Windows games using the Wine compatibility layer. It installs and launches the Windows version of the Steam client, installs and launches games from your Epic Games and GOG libraries, and runs other Windows games you add yourself. The App does not include or redistribute any store's software or games: Steam is downloaded from Valve's servers, and Epic Games and GOG games are downloaded from those stores' own servers using the open-source clients Legendary and gogdl. You are responsible for having the right to play any game you add to the App.
