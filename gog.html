Questions

Do I need GOG Galaxy?

No. Game Bridger signs in to GOG and installs your games itself.

I already downloaded GOG installers. Can I use them?

Yes. Open the Other games page in Game Bridger and drop the installer on it.

Will every GOG game run?

Most do, since GOG games have no DRM, but games that need DirectX 12, like Cyberpunk 2077, won't start; they're marked on the shelf above. Try yours during the 10 free days.

Is Game Bridger made by GOG?

No. Game Bridger is an independent app and is not affiliated with, endorsed by or sponsored by GOG or CD PROJEKT. Games download from GOG's own servers.

Is it an emulator or a virtual machine?

Neither. Game Bridger uses Wine, a compatibility layer that lets Windows apps run directly on macOS, plus DirectX support for games. There's no copy of Windows to install or pay for.

How do I cancel or uninstall?

Cancel from the link in your receipt email at any time. To remove the app, use Game Bridger → Uninstall Game Bridger. It removes only what Game Bridger installed.
