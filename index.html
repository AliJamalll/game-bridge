Questions

Is it an emulator or a virtual machine?

Neither. Game Bridge uses Wine, a compatibility layer that lets Windows apps run directly on macOS, plus DirectX support for games. There's no copy of Windows to install or pay for.

Do I need to buy my games again?

No. You sign in to your own Steam account and use the games you already own.

Will every Windows game work?

Not every game. Many games run well, but titles with very new graphics features may not start. Games whose anti-cheat doesn't run on a Mac, like Apex Legends or Rainbow Six Siege, are marked in the app, which offers to play them on GeForce NOW where it's available, or to stream them from your own Windows PC with Steam Link. Try your games during the free trial before subscribing.

What does the trial include?

Everything. After 10 days, choose a monthly or yearly subscription to keep using Game Bridge.

Can I install games on an external drive?

Yes. Plug it in, open Steam from Game Bridge, then go to Steam → Settings → Storage → Add Drive.

Is Game Bridge made by Valve?

No. Game Bridge is an independent app and is not affiliated with, endorsed by or sponsored by Valve Corporation. Steam is downloaded directly from Valve's servers.

How do I cancel or uninstall?

Cancel from the link in your receipt email at any time. To remove the app, use Game Bridge → Uninstall Game Bridge. It removes only what Game Bridge installed.
