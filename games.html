Questions

What can I add?

A Windows game's .exe, or the installer it came with (.exe or .msi).

Can I use an installer from a disc?

Yes. Copy it to your Mac or open it from the disc, then drop it on the Other games page.

Will every Windows game run?

Not every one. Games whose anti-cheat doesn't run on a Mac, like Fortnite, Valorant, Overwatch 2, Call of Duty and Apex Legends, won't start, and neither will games that need DirectX 12, like Diablo IV; they're marked on the shelf above. Try yours during the 10 free days.

The game has a Mac version. Should I use this?

Use the Mac version when there is one. Game Bridge is for games that only come for Windows.

Is it an emulator or a virtual machine?

Neither. Game Bridge uses Wine, a compatibility layer that lets Windows apps run directly on macOS, plus DirectX support for games. There's no copy of Windows to install or pay for.

How do I cancel or uninstall?

Cancel from the link in your receipt email at any time. To remove the app, use Game Bridge → Uninstall Game Bridge. It removes only what Game Bridge installed.
